## Message on Demand – where darkness meets the web.

Hey, there! This is a website template created with Next.js and styled with TailwindCSS. It has built-in support for dark mode and Next-SEO for the perfect SEO optimizations.

## 🚀 Quick Start

1. Clone the repository:
   ```bash
   git clone https://github.com/minor/messageondemand.git
   cd messageondemand
   ```
2. Install dependencies:
   ```bash
   yarn install
   ```
3. Start dev server:
   ```bash
   yarn dev
   ```

## 🛠 Features
- **Next.js**: Hybrid SSG and SSR
- **TailwindCSS**: Utility-first styling
- **Dark Mode**: System-aware theme toggling
- **Next-SEO**: OpenGraph and meta tag configuration
